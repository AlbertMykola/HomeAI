# Archived XIB authoring utilities

The current app UI is edited directly in `HomeAI/Storyboards/*.storyboard`.
Controllers use `AppStoryboard`, cells are storyboard prototypes, and reusable components are inline storyboard hierarchies.

These historical specifications are retained only as migration/reference material. They are not a build step and must not be run to recreate the removed XIBs for the current app.
